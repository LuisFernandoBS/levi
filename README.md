# Levi Baby Shower (PWA)
Projeto estático + 1 função serverless. Sem build.
1. Suba esta pasta em um repositório do GitHub e importe no Vercel (Framework: Other).
2. Em Settings > Environment Variables, crie `GEMINI_API_KEY` (e, se quiser, `GEMINI_MODEL`). Faça redeploy.
3. Sem a chave, a Levi AI responde em modo demonstração.
Os dados ficam no localStorage do aparelho (dados fictícios iniciais).
